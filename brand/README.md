# Offisiell BDO-logo

Legg den offisielle logofilen her som `bdo-logo.svg` (foretrukket) eller `bdo-logo.png`
(transparent bakgrunn, minst 1200 px bred). Alle filmene henter den automatisk på sluttkortet.
Kjør deretter `node <film>/build.mjs` for hver film for å bygge HTML-filene på nytt.

For hjørnesteinen (cornerstone, rød med hvit logo) trengs også den hvite logoen: `bdo-logo-white.png` (eller `.svg`).
