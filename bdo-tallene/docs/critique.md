# Kritikk: Tallene forteller

Runde 1 (hook / lesbarhet / bevegelse / variasjon / merkevare: 3/3/3/4/3)
- Horisontlinje kuttet gjennom åpningstallet; fjernet til linjen er en overgang.
- Innkjøp- og salgsbeløp kolliderte på tidslinjen; Salg fikk høyere stilk.
- Tom ramme i scene 4 mellom søyler og prikkmatrise; strammet timing.
- Etikett for avvik overlappet; punktene flyttet til ulike høyder.

Runde 2 (4/4/4/4/4)
- Tett linjefelt flyttet unna bildetekst. Tomme rammer rundt 55 s og 67,5 s fylt: overskrifter og logo starter tidligere.
- Rød brukes kun på ett punkt per scene (salg, siste prikk, flaggede punkter, siste datapunkt).

Runde 3 (4/4/4/5/4)
- Kontrollert telefonvisning: all tekst >= 34 px unntatt mono-akser.
- Verifisert at rammetid er under 30 ms for de fleste scener (site-scenen ca. 28 ms, programvare-rendering).
